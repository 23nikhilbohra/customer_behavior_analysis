Customer Shopping Behavior Analysis
Overview

This project focuses on analyzing customer shopping behavior to uncover business insights and support data-driven decision-making. The workflow includes data loading, exploratory data analysis (EDA), data cleaning, SQL-based analysis, dashboard creation in Power BI, report generation, and presentation design using Gamma.

The analysis is based on customer purchase data containing demographic information, shopping patterns, product preferences, and spending behavior.

Dataset

The dataset contains customer shopping transaction records with demographic and purchasing information.

Dataset Highlights
Total Records: 3,900 purchases
Columns: 18 features
Key Features Include:
Customer demographics
Purchase amount
Product category
Subscription status
Shipping preferences
Discount usage
Customer ratings
